# sample_data · 演示用假数据

> 本目录全部内容由 [`generate_sample_data.py`](generate_sample_data.py) 生成，**零真实业务信息**：
> 公司名、人名、发票号、金额均为虚构示例，与任何真实企业无关。

## 用途

为 `docs/demo/run_replay.py` 提供可运行的输入数据，使核心脚本能在隔离工作区中
**真实执行**并采集日志与产物（用于 `docs/demo/console.html` 的回放演示）。

> 公开仓库仅包含演示层：业务脚本的实现未公开，本目录用于保证数据契约清晰、回放链条可复现。

## 与脚本的对接约定（生成时刻意对齐的解析规则）

> **目录约定（重要）**：脚本把**「脚本所在目录的上一级」**当作数据目录（源自早期"脚本平铺在项目根目录"的布局）。
> 因此正确摆法是：**脚本放进数据目录的下一级子目录**（如 `<工作目录>/accounting/xxx.py`），数据放 `<工作目录>/`。
>
> - `compare_vouchers_advanced.py` / `split_vouchers_凭证PDF拆分.py`：数据路径由命令行参数或弹窗指定，输出落在输入文件同级
> - `namelistget_feishu_v9.py`：`namelist.xlsx` 需在「脚本上一级」目录；结果写入该目录下的 `搜索结果/`
> - `bankStatementSplitterBasedOnJournal.py`：要求「脚本上一级」目录下**恰好一个**流水 PDF + **恰好一个**含「日记账」的 xlsx
> - 一键按此约定运行（自动摆好布局、仓库根零污染）：`python docs/demo/run_sample.py <样例名>`

| 数据 | 约定 |
|------|------|
| 发票 PDF 文本 | `发票号码：<8 位或 20 位>`（全角冒号）；纸质票另含 `发票代码:<8 位>`（半角冒号） |
| 发票台账 | 工作表 `发票基础信息`，同时提供 `发票号码` / `数电票号码` / `数电发票号码` 三列 |
| 审批单 PDF | `申请编号:<数字>`（半角冒号）、`单据编号 <编码>`（空格分隔）、`申请人 <姓名>（部门）`、`审批状态 <状态>` |
| 记账凭证 PDF | 每页含 `日期: YYYY-MM-DD` 与 `凭证号: 记-001-1/2`（{凭证号}-{页号}/{总页数}） |
| 日记账 xlsx | A 列标签从第 5 行起，末两行为合计/制表人 |
| 利润表 xlsx | 第 3 行 C 列为月份；第 4 行起 A/B/C = 项目/行次/金额 |
| 现金流量表 xlsx | 第 4 行起 A/C/E = 项目/行次/金额 |

## 重新生成

```bash
python sample_data/generate_sample_data.py
```

生成 PDF 时优先嵌入系统字体（黑体/雅黑），确保 pdfplumber / pypdf / PyMuPDF 三条链路的文本提取一致。
