## 一、审查规则

| 级别 | 规则 |
| ---- | ---- |
| **硬违规**（必须清零） | 本机工作区路径、真实主体黑名单（公司名/人名）、密钥口令赋值、手机号、邮箱、身份证号、内网 IP |
| **提示项**（逐项人工确认） | 其他盘符路径（占位符 / 测试路径 / 系统字体路径可放行）、公司代码样式 token（`字母+数字` 前缀，配安全词白名单） |
| **反向排查** | 从 `202602/` 真实业务数据文件名提取人名与公司词，反查全部公开文件 |

扫描器可随时复跑：`python docs/demo/sensitive_check.py`（退出码 0 = 通过）。
